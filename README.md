# GNesis

GNesis (**G**raph <ins>ge**Nesis**</ins>) is a playground for exploring graph generation concepts.

### Generators

- Erdős-Rényi
- Barabási-Albert
- Watts-Strogatz
- Stochastic Block Model (Planted Partition Model for simplicity)
- Random Geometric Graph

### Metrics

- Degree distribution
- Closeness centrality
- Ricci curvature
- Filtration curve

### Notes

- Portions of this codebase were developed with the assistance of an AI.
